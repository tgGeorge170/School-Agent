    🔊 Podešavanje glasa
    Tražim glasove na uređaju…
    Nemam dobar glas — šta da radim?

    Ne mora biti baš srpski glas. Hrvatski i bosanski čitaju našu latinicu potpuno isto — ista slova, isti izgovor, a hrvatski je uz to ijekavski kao i mi. Aplikacija ih sama bira odmah poslije srpskog. Zato je najlakše instalirati hrvatski glas, koji postoji i na Windows-u i na Mac-u.

    Windows (bilo koji pregledač): Podešavanja → Vrijeme i jezik → Jezik i region → Dodaj jezik → Hrvatski → čekiraj „Govor / Text-to-speech” i instaliraj. Zatvori i ponovo otvori pregledač — pojaviće se glas Microsoft Matej. Windows nema nijedan srpski glas, pa je ovo najbolje što se dobija bez interneta.

    Mac (bilo koji pregledač): Podešavanja sistema → Pristupačnost → Izgovoreni sadržaj → Sistemski glas → Upravljaj glasovima → Hrvatski → Lana → preuzmi.

    Android: Podešavanja → Pristupačnost → Text-to-speech → Google Speech Services → Jezik → Srpski → preuzmi. Android jedini ima pravi srpski glas i radi bez interneta.

    iPhone: Podešavanja → Pristupačnost → Izgovoreni sadržaj → Glasovi → Hrvatski.

    Linux: sudo apt install espeak-ng speech-dispatcher — dobiješ srpski glas odmah, ali robotski.

    Ako hoćeš najprirodniji glas: Microsoft Edge ima besplatne „Online (Natural)” glasove i među njima pravi srpski, bez ikakve instalacije. To je jedino mjesto gdje taj glas postoji na laptopu — ne moraš ga koristiti, ali zvuči najbolje.

    Ako ništa od ovoga ne možeš, ostavi strani glas i uključi kvačicu „Prilagodi izgovor” iznad — tekst se prepiše tako da strani glas ispadne što bliži našem.
